# ASSETS — THE LAST SIGNAL (90 s)

Everything external the new production uses, with source, licence and credit. Everything else
(black hole, disk, lensing, ship geometry and materials, debris, dust, sound) is generated by code in
`production/`. Downloads are fetched by scripts (never committed) into `production/cache/`.

THE LAST SIGNAL is a non-commercial short film.

Adobe Fonts was searched first (connector, 2026-09-29). Its fonts are activated through Creative Cloud
and cannot be fetched as files by a scripted, reproducible pipeline, and the suggestions for this brief
were stock sci-fi display faces (Orbitron, Major Mono, Bebas); so the title uses the OFL font above.
